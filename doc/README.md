# Diseños

Cada componente tiene aquí su diseño, con el nombre `xxx_design.md`. El diseño se escribe antes que el código.

| Componente | Código | Diseño |
|---|---|---|
| Nodo sensor | `src/arduino` | `arduino_design.md` |
| App del portador | `src/app` | `app_design.md` |
| Servidor REST | `src/servidor_rest` | `servidor_rest_design.md` |
| Lógica de negocio | `src/logica` | `logica_design.md` |
| Base de datos | `src/bd` | `bd_design.md` |
| Web pública y Mi cuenta | `src/web_publica` | `web_publica_design.md` |
| Panel de administración | `src/web_admin` | `web_admin_design.md` |
| Previsión de ozono (IA) | `src/prevision` | `prevision_design.md` |
